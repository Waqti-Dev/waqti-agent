# Waqti Agent

Waqti is a native, phone-first AI agent built from a clean repository.

## Principles

- Start from a clean architecture; do not inherit OpenDroid's architecture.
- Reuse mature external work when it is technically superior to reinventing it.
- Preserve hard-won engineering knowledge in this repository.
- Every milestone must have executable acceptance criteria.
- Local-first and privacy-aware by default.
- Build a real agent, not a documentation demo.
